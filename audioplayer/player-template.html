🎵 ROKKO Audio Player

Shared audio player component for ROKKO Records

Features

  • Full-screen overlay player with waveform visualization
  • Vinyl spinning animation synchronized with playback
  • Responsive design (desktop, tablet, mobile)
  • Keyboard shortcuts (Space = play/pause, Esc = close, Arrows = seek)
  • Progress bar with click-to-seek
  • Streaming platform buttons (Beatport, Spotify, Apple Music, SoundCloud)
  • Automatic metadata loading from artist folders
  • Cross-origin audio support with CORS

Usage

Option 1: Load from artist folder

RokkoPlayer.openPlayer({ artistFolder: 'mp3/SkaRamushVandango', startIndex: 0 })

Option 2: Custom playlist

RokkoPlayer.openPlayer({ playlist: [{title, artist, audioSrc, coverSrc}, ...], startIndex: 0 })

Known Limitations

  • CORS: Waveform visualization requires audio files to be served with proper CORS headers
  • Streaming links: Currently placeholder links - update data-url attributes with actual URLs
  • Assets: Requires assets folder with vinyl.png, tonearm.png, avatar.png, and platform logos
