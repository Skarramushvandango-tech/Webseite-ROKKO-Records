🎵 ROKKO Records Audio Player

Vanilla JS Component with Waveform Visualization

Features

  • WebAudio API waveform visualization (orange #d77014)
  • Vinyl record with rotation animation
  • Tonearm that moves during playback
  • Keyboard shortcuts: Space (play/pause), Esc (close), Arrow keys (prev/next)
  • ARIA labels for accessibility
  • Click waveform to seek
  • Auto-advance to next track
  • Streaming service links

Usage

Include the player in your page:

<link rel="stylesheet" href="player-styles.css">
<script src="player-component.js"></script>

Open the player programmatically:

window.RokkoPlayer.openPlayer({ playlist: [...] });
