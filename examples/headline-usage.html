ROKKO Style System - Demo Page

Diese Seite demonstriert die neuen Styling-Klassen für das ROKKO Records Layout basierend auf dem Screenshot-Design. Alle Komponenten verwenden eine zentrale Farbpalette mit dunklen Rahmen und heller sandfarbener Innenfläche.

Headline Images

Headline-Bilder (z.B. beats.png, news.png) werden breiter angezeigt mit weniger Abstand zum Rahmen. Sie haben einen abgerundeten Rahmen und Schatten für mehr Tiefe.

Frame System

Das Frame-System verwendet einen dunklen braunen Außenrahmen mit einer hellen sandfarbenen Innenfläche.

Beispiel Frame

Dieser Container demonstriert das Frame-System: Ein dunkler brauner Rahmen (--rokko-brown-dark / #3D2817) mit einer hellen sandfarbenen Innenfläche (--rokko-sand / #E0C290).

Artist Carousel

Das Artist-Karussell hat eine sandfarbene Innenfläche, abgerundete Cover mit Schatten und runde Pfeil-Buttons an den Seiten.

Farbpalette

Alle Farben sind als CSS-Variablen definiert für einfache Anpassungen:

--rokko-sand
#E0C290
--rokko-brown
#201613
--rokko-brown-dark
#3D2817
--rokko-accent
#d9af6b

Audio Player Widget

Der Audio-Player verwendet das gleiche Frame-System mit sandfarbener Innenfläche und dunklem Rahmen.
