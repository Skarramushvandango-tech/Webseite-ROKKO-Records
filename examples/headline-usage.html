CSS Klassen Übersicht

Die folgenden CSS-Klassen können für Headline-Bilder verwendet werden:

  • .headline-img - Hauptklasse für Headline-Bilder
  • .headline-image - Alternative Klassennamen
  • .banner-image - Alternative für Banner-Style

CSS Farbvariablen

:root { --rokko-sand: #E0C290; /* Light sand color for interior frames */ --rokko-brown: #201613; /* Dark brown for text */ --rokko-brown-dark: #3D2817; /* Dark brown for frame borders */ --rokko-accent: #D4B584; /* Accent sand color */ }

Frame Styling

Alle Haupt-Sections haben jetzt:

  • Hellsandfarbenen Innenbereich (background: var(--rokko-sand))
  • Dunkelbraunen Rahmen (border: 6px solid var(--rokko-brown-dark))
  • Abgerundete Ecken (border-radius: 8px)

Testing Instructions

  1. Öffne index.html im Browser
  2. Überprüfe, dass alle Headline-Bilder breit dargestellt werden
  3. Überprüfe, dass Sections hellsandfarben mit braunem Rahmen sind
  4. Teste das Artist-Karussell auf korrekte Darstellung
  5. Überprüfe, dass die Carousel-Pfeile rund sind und am Rand positioniert sind

Geänderte Dateien

  • styles/override-rokko.css - Hauptstil-Datei mit allen neuen Styles
