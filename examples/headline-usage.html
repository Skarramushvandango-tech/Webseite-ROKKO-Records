ROKKO Records - Visual Styling Demo

1. Brown Frame with Sand Interior

Usage: Use class .rokko-frame for brown frame with sand interior background.

Example Frame Content

This demonstrates the brown frame (6px border, dark brown #3D2817) with light sand-colored interior (#E0C290). The frame creates a cohesive visual identity throughout the site.

2. Headline Images - Wider Display

Usage: Use class .headline-img or .headline-banner for section headers.

The headline images now display wider with minimal margin to the frame border, using object-fit: cover for proper scaling.

Another example with the crew headline image showing the consistent styling approach.

3. Artist Carousel with Rounded Covers

Usage: Use .artist-carousel wrapper with .carousel-track for horizontal scrolling.

Features: Sand-colored background, rounded covers (12px radius), box shadows (0 6px 16px), hover effects with scale and lift.

4. Album Carousel with Navigation Arrows

Usage: Horizontal scrollable carousel with round navigation arrows (requires carousel-simple.js).

Features: Round arrow buttons (50px diameter), sand border (3px), smooth scroll behavior, hover scale effects.

5. Audio Player Widget Example

Usage: Use .audio-player-widget for styled audio player containers.
Set the Fire - Skaramush Vandango

Features: Sand background, dark brown border, rounded corners, shadow effects for depth.

6. CSS Variables Reference

Available CSS Variables:

  • --rokko-sand: #E0C290 (Light sand for backgrounds)
  • --rokko-brown: #201613 (Dark brown for text/accents)
  • --rokko-brown-dark: #3D2817 (Dark brown for frames)
  • --rokko-accent: #B8935F (Accent sand/brown)
  • --carousel-arrow-bg: rgba(224, 194, 144, 0.95) (Arrow background)

Implementation Notes

To Use These Styles:

  1. Include styles/override-rokko.css in your HTML
  2. For carousel functionality, include assets/js/carousel-simple.js
  3. Apply appropriate classes to your HTML elements
  4. Use the CSS variables for consistent theming

Key Features:

  • All brown frames have light sand-colored interiors
  • Headline images display wider with minimal margin
  • Carousel covers are rounded with shadows for depth
  • Navigation arrows are round with sand-colored borders
  • Fully responsive for mobile devices
  • No functional changes to audio player (only visual styling)
